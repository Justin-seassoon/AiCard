## 1. 设备接入与配网（打底）✅

**目的**：确认设备能注册、握手建连、上报状态，云端能识别在线/睡眠。

| 步骤 | 操作 | 真机预期 | 云端核对点 |
|---|---|---|---|
| 1.0 | 后台「设备管理」页签，填真实 `device_id`（可带 `staff_language`/姓名/工号）→ 注册 | 页面显示该设备的 token（仅本次显示，立即保存） | 后台「设备列表」出现该设备 |
| 1.1 | 用注册的 `device_id + token` 连 WSS（`scope=translate`） | 握手成功（HTTP 101），不报 403 | 后台无直接页面；用「诊断日志」确认设备有日志，或看云端日志 |
| 1.2 | 设备发 `session_init` | 建立会话 | 云端 `initSession` 记录 session、`markOnline` |
| 1.3 | 设备进入睡眠 / 发 `sleep_notice` | 屏幕显示睡眠 / 低功耗 | `DeviceStateTracker` 状态变 `sleep` |
| 1.4 | 断开 WSS | 回待机 | 云端 `afterConnectionClosed`：清 session + 标 sleep + 注销连接 |

**验收**：真机连上即在线、断开即回收；`session_init` 里 `staff_language` 能正确影响后续问答/翻译方向。

## 2. 翻译对话（核心，优先级最高）🟡

**目的**：短按翻译键跑通「建连 → 流式 → VAD 断句 → LID 判向 → TTS 外放 → 连续轮流 → 20s 熔断」。

### 2.1 基础闭环

| 步骤 | 操作 | 真机预期 | 云端核对点 |
|---|---|---|---|
| 2.1 | 短按翻译键，员工说一句（如日语「こんにちは」） | VAD 断句后约 1.5s 内播中文译文 TTS | 云端走「LID 判向 → ASR → MT → TTS」，`0x81` 分片下发 |
| 2.2 | 游客回一句中文 | 播日语译文 | LID 判游客方向、翻译为 `staff_language` |
| 2.3 | 连续轮流对话，中途不重复按键 | 每轮自动断句 + 翻译 | 会话级连续，`turn_id` 逐轮更换 |
| 2.4 | 连续 20s 不说话 / 不按键 | 自动结束会话、进低功耗 | 云端会话回收（`E_SESSION` / 断连清理） |

### 2.2 真机重点验证项

| 项 | 操作 | 预期 | 备注 |
|---|---|---|---|
| auto 判向 | 员工先说话、游客后说话交替 | 方向不判错、不无音频 | 员工先说话无 `visitor_language` 时按 `lang_pair` 兜底 |
| 无音频回归 | 各说一句 | 均有 TTS | 本周已修「说话方未知按 LID 判向」 |
| 采播互斥（AEC） | 播 TTS 时说话 | 无啸叫、能打断 | 端侧 AEC 通路（甲方硬要求） |
| 高频语言对切换 | 中日/英日/韩日循环切 | 屏幕语言对正确、翻译方向正确 | 实体语言键循环 |
| 低频语言对 | 切到泰/越/法等 ⇄ 日 | 菜单/后台配置生效 | 低频经彩屏菜单或后台 |

**验收**：核心业务链端到端跑通，端到端延迟目标 < 1.5s（理想接近 1s）。

## 3. 员工问答（staff_qa）🟡

**目的**：问答键走知识库检索 → 流式 TTS；验证提速后的端侧兼容。

| 步骤 | 操作 | 真机预期 | 云端核对点 |
|---|---|---|---|
| 3.1 | 短按问答键，问「朝食は何時からですか」 | 先回 `answer` 文本、再流式 TTS，端到端 0.7~0.9s（缓存命中） | `answer` 帧 + `0x81` 分片 + `tts_end` |
| 3.2 | 中文员工问（切 `staff_language=zh-CN`） | 跨语言检索 + 双语答案 | 非日语走 `answerLocalized`，一次生成日/中 |
| 3.3 | 问知识库未覆盖的问题 | 播「知識ベースに明確な記載がありません」 | `SkbResult.noMatch()` 以 answer 帧回（非 error） |
| 3.4 | 连续问同一问题（5 分钟内） | 明显更快（缓存命中） | `QaAnswerCache` 命中，跳过检索+LLM |

**提速兼容回签（R1–R6）**——真机逐项确认，重点 2 条：
- **R2 首帧 WAV 头**：答案 TTS 首帧带 44 字节 WAV 头、长度字段写 0，端侧跳过。
- **R4 `stop_tts` 后丢帧**：打断后本地丢弃后续帧；服务端停发是已知缺口（真机实测再定）。

## 4. 会议录音 🟡

**目的**：长按录音 → 分片上传 → 转写纪要；验证断电续传、缺片补传、超时收尾。

| 步骤 | 操作 | 真机预期 | 云端核对点（后台「会议纪要」页签） |
|---|---|---|---|
| 4.1 | 长按开始录音，说一段话，长按结束 | 分片上传完成 | 会议状态 `recording → uploading → transcribing → draft` |
| 4.2 | 结束时有缺片（人为中断） | 收到 `missing_seqs`，保持 `uploading` 可补传 | `end` 返回 `missing_seqs`，不转写 |
| 4.3 | 补传缺片后再 `end` | 自动转写 | 补齐自动转写（无需再 end） |
| 4.4 | 录音中途断电 → 重连续传 | 按 seq 幂等续传 | 10 分钟无新片自动 finalize |
| 4.5 | 转写/纪要完成后 | 后台可见纪要 + 待办 | 后台「会议纪要」页签审核、导出 docx |

**接口**（端侧实现，云端已部署）：
- `POST /api/v1/meetings`（`client_key` 幂等，带 `fw_version`/`features`/`trigger`/`notice_played`）
- `PUT /api/v1/meetings/{id}/chunks/{seq}`（seq + sha256）
- `POST /api/v1/meetings/{id}/end`（`last_seq`）、`GET /api/v1/meetings/{id}`（status）
- 鉴权 `Authorization: Bearer <token>` + `X-Device-Id`

## 7. 异常与兜底场景（逐场景验收）

> 每个场景「真机提示」肉眼确认、「云端状态」用诊断日志 + 错误码远程核对；「端侧无提示或云端无状态」即登记为待修缺口。

### 7.1 接入/连接层

| 场景 | 触发 | 真机提示 | 云端状态 |
|---|---|---|---|
| 鉴权失败（WSS） | 握手 device_id+token 错 | 握手 403，提示重新鉴权 | 拒绝握手，`E_AUTH` 记日志 |
| 鉴权失败（HTTP） | OTA/会议/日志 token 过期 | 401 / `E_MEETING_AUTH` / `E_DEVICE_LOG_AUTH` | 拒绝，要求刷新凭证 |
| 断网/心跳超时 | WS ping/pong 10s，2–3 次无 pong | `E_NET` 提示音 + 重连；本地打断仍可用 | 断连清理会话缓冲 |
| 20s 会话空闲熔断 | 20s 无语音/按键 | 自动结束、回待机 | 会话回收（正常结束，非故障） |

### 7.2 翻译链路

| 场景 | 触发 | 真机提示 | 云端状态 |
|---|---|---|---|
| LID 低置信降级 | `conf < 0.8` 且非白名单 | `E_LID_LOW` 播「请再说一遍」，不外放 | 记低置信日志 |
| 语言漂移防护 | 高置信新语言 ≠ 锁定语言 | 本句照译，连续 2 次或 ≥0.95 才切 | pending 软锁定累加 |
| 供应商全挂 | 已降级仍失败 | `E_PROVIDER` 播「服务暂不可用」 | 供应商路由穷尽 |
| ASR 失败 | ASR 出错 | `E_ASR_FAIL` 提示重试 | 切备选供应商 |
| 输入冲突 | 重叠讲话 | `E_CONFLICT` 播「请依次说话」 | 丢弃该轮 |
| 双方同语言 | 游客说员工语言 | `E_SAME_LANG` 不翻译/直通 | no_translate |

### 7.3 员工问答

| 场景 | 触发 | 真机提示 | 云端状态 |
|---|---|---|---|
| 知识库无匹配 | 检索未命中 | 播「暂无明确说明」 | `qa_log(no_match)` → 缺口池 |
| 范围外问题 | ⬜ 本轮挂账 | （预期走 no_match） | — |

### 7.4 会议录音

| 场景 | 触发 | 真机提示 | 云端状态 |
|---|---|---|---|
| 缺片补传 | `end` 有缺片 | 收到 `missing_seqs`，保持 `uploading` | 补片只接受 `seq ≤ expected_last_seq` |
| 断网/断电续传 | 长录音中断连 | 重连按 seq 幂等续传 | 10 分钟无新片自动 finalize |
| 转写失败 | ASR/LLM 出错 | 后台该会议显示 `failed` | `failed`，可 `regenerate` |
| 分片校验失败 | 同序号内容不一致 | `E_MEETING_SHA_MISMATCH` 重传 / `E_MEETING_SEQ_CONFLICT` 停该片 | 幂等 + 校验 |
| 音频过期 | 30 天到期 | `E_MEETING_EXPIRED` | 删音频、留转写纪要 |

### 7.5 广播 / OTA / 诊断日志

| 场景 | 触发 | 真机提示 | 云端状态 |
|---|---|---|---|
| 广播离线补拉 | 下发时离线 | 重连后收到补发 | 未投递标记录，重连补发 |
| OTA 版本不降级 | 设备版本 ≥ 目标 | `update_available=false` + `reason` | `UP_TO_DATE`/`NO_APPLICABLE_RELEASE` |
| OTA 下载校验 | sha256 不符 | 丢弃重取 | 签名 URL 短期有效 |
| 日志频率/超限 | 1 分钟内重复/超 256KB | `E_DEVICE_LOG_RATE_LIMIT` 退避 / `TOO_LARGE` 减日志 | 1 次/分钟、保留 7 天 |
