### 3.2 HTTPS（模拟器用，待运维放通 80/443）

Caddy 已在服务器部署（host 网络，监听 80/443），配置 `/tmp/aicard/Caddyfile`：

```
aicard.seassoon.net {
    reverse_proxy localhost:8082
}
```

运维需完成（否则 Let's Encrypt 签不下来证书）：

1. 确认域名 `aicard.seassoon.net` 解析到的公网 IP（日志曾显示 `120.253.215.100`，与预期 `.108` 需核对）。
2. 放通该公网 IP 的 **TCP 80**（Let's Encrypt HTTP 验证）和 **TCP 443**（HTTPS），映射到内网 `10.0.189.32` 的 80/443。

放通后 Caddy 自动申请/续期证书，业务同事即可访问 `https://aicard.seassoon.net/simulator.html`（麦克风可用）。

## 七、知识库重灌（完整流程）

知识库用灌库器 `KnowledgeSeeder` 在应用启动时灌入。V7 起 chunk 新增 `answer_embedding`（校验用答案向量）、V8 新增 `keywords`（关键词兜底），旧数据这两列为 NULL 会被校验/兜底跳过，需**清空重灌**才生效。

### 7.1 构建 + 上传新 jar

```bash
# 本地构建（注意 JAVA_HOME 指向 JDK17，否则 Lombok 编译失败）
JAVA_HOME=<jdk17> mvn clean package -DskipTests

# 上传 jar + 知识库 md 到服务器（覆盖旧文件）
scp target/aicard-0.1.0-SNAPSHOT.jar \
  docs/VKB游客FAQ-日语版.md \
  docs/演示知识库-便利店与免税店-日语版.md \
  docs/演示知识库-连锁酒店-日语版.md \
  root@10.0.189.32:/tmp/aicard/
```

### 7.2 重建镜像

```bash
cd /tmp/aicard && docker build -t aicard:latest .
```

### 7.3 复用环境变量（密钥不出服务器）

应用密钥（DB_PASSWORD / AZURE_OPENAI_KEY / AZURE_SPEECH_KEY / AIBRIDGEX_KEY）只存在旧容器，不落盘。重灌前从旧容器导出复用：

```bash
docker exec aicard-app sh -c 'printenv > /tmp/env_dump.txt'
docker cp aicard-app:/tmp/env_dump.txt /tmp/aicard.env
```

### 7.4 停容器 + 清空表

```bash
docker stop aicard-app && docker rm aicard-app
docker exec aicard-postgres psql -U root -d db_ai_card \
  -c "TRUNCATE chunk, document RESTART IDENTITY CASCADE;"
```

### 7.5 灌 SKB + VKB

> ⚠️ **关键坑**：Dockerfile 的 `ENTRYPOINT` 已是 `java -jar app.jar`，所以 `docker run` 后面**只传 `--skb.seed.*` 参数，不要再写 `java -jar app.jar`**——否则会拼接成 `java -jar app.jar java -jar app.jar --skb.seed...`，seeder 参数失效、只灌进 1 条。

```bash
# 灌 SKB（便利店 + 连锁酒店，domain=skb，预期 38 document）
docker run -d --rm --name seed-skb --env-file /tmp/aicard.env \
  -v /tmp/aicard:/app/kb -p 18080:8080 aicard:latest \
  --skb.seed.enabled=true --skb.seed.domain=skb \
  --skb.seed.files=/app/kb/演示知识库-便利店与免税店-日语版.md,/app/kb/演示知识库-连锁酒店-日语版.md \
  --skb.seed.customer-id=1 --skb.seed.store-id=1

# 等灌完（docker logs seed-skb 看到「灌库完成」，或轮询 document 计数达到 38）
docker stop seed-skb

# 灌 VKB（游客 FAQ，domain=vkb，预期 21 document）
docker run -d --rm --name seed-vkb --env-file /tmp/aicard.env \
  -v /tmp/aicard:/app/kb -p 18081:8080 aicard:latest \
  --skb.seed.enabled=true --skb.seed.domain=vkb \
  --skb.seed.files=/app/kb/VKB游客FAQ-日语版.md \
  --skb.seed.customer-id=1 --skb.seed.store-id=1

docker stop seed-vkb
```

### 7.6 正常启动 + 验证

```bash
# 正常启动（不带 --skb.seed.* 参数，避免每次重启重复灌库）
docker run -d --name aicard-app --restart always --env-file /tmp/aicard.env -p 8080:8080 aicard:latest

# 验证
docker exec aicard-postgres psql -U root -d db_ai_card \
  -c "SELECT domain, count(*) FROM document GROUP BY domain;"   # 期望 skb=38 / vkb=21
curl http://localhost:8080/actuator/health                       # 期望 {"status":"UP"}
```

> 完整脚本版见 `deploy-docs/reseed.sh`（`scp` 到服务器后 `bash /tmp/reseed.sh`）。
