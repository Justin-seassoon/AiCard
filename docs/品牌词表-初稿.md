# 品牌名/型号词表 · 初稿

> 用途：质量门控的「品牌词」过滤（spec §7.4 ② 的 BRAND 分类）。游客说出这些词时，翻译**照常播放**，但不更新语言记忆——避免品牌名（跨语言念法一致）误导 LID 判定、造成软锁定漂移。
>
> - **匹配方式**：包含匹配（文本里含这个词即命中），大小写不敏感。
> - **配置位置**：`src/main/resources/application.yml` 的 `translation.qualify.brand-terms`，逗号分隔。
> - **当前状态**：已填入 `application.yml`——「通用」+「免税店/便利店」+「连锁酒店」三批；「机场」批暂未启用（知识库未覆盖，留待后续）。

## 使用建议

1. **先启用**「通用」批 + 你当前演示场景对应的一批，其余留空。
2. **只配门店里真会出现的词**。配多了不伤性能（`Set.contains` 是 O(1)，包含匹配只多一次遍历），但配错的词会误伤正常句子。
3. **短词别放这里**——像 `OK`、`yes`、`はい` 这类极短词应放「短词白名单」（精确匹配），放品牌词表（包含匹配）会误命中含它的句子。
4. **别配普通常用词**——如 `hotel`、`card`、`tax`，会把正常对话误判成品牌词。
5. 型号词（如 `iPhone 15`、`CP-1`）若需要，同样按「包含匹配」加进去；但型号太多，建议门店按需自配。
