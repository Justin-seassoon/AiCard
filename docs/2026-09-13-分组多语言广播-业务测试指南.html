分组多语言广播 · 业务测试指南
v1.0 · 2026-09-13 · 通过云端模拟器测试

一、这是什么功能

管理员发一条通知，云端自动翻译成每个工牌各自的母语，推送到各工牌显示并播报；员工按「确认收到」回执，管理员在后台看谁已收到、谁没收到。

典型场景：工地多国劳工的统一命令传达、安全须知、信息确认等「一对多」通知。

二、测试准备

  • 浏览器：Chrome（推荐）。
  • 访问地址：https://aicard.seassoon.net/（工牌模拟器页面）。
  • 已预置：一个「群」（群 ID = 1），群里有 3 台工牌：demo-device-001（日语）、test-dev-002（日语）、dev-vi-001（越南语）。

    • 三、测试步骤

    步骤 1：开 3 个标签页，模拟 3 台工牌

  • 打开 https://aicard.seassoon.net/，再复制出 2 个标签页（共 3 个）。
  • 每个标签页在「device_id」输入框分别填：demo-device-001 / dev-vi-001 / test-dev-002。
  • 每个标签页点「连接」按钮（3 个都要连）。

    • 步骤 2：发广播（管理员操作）

  • 在任意一个标签页，往下找到「📢 分组广播」区域。
  • 群 ID 保持 1；源语言选「ja-JP（日语）」；输入广播内容（如：安全须知，请佩戴安全帽）。
  • 点「发送广播」按钮。

    • 步骤 3：观察工牌收到广播

  • 三个标签页的「本机收到的广播（墨水屏模拟）」区域会显示译文，扬声器同时播报。
  • 预期：日语工牌显示日语原文，越南语工牌显示越南语翻译。

    • 步骤 4：回执

  • 每个标签页点「✅ 确认收到」按钮，表示该工牌已确认收到。

    • 四、重点测试点

    #测试点操作预期结果
    1多语言翻译发一条日语广播越南语工牌显示越南语，日语工牌显示日语原文
    2回执收到广播后点「确认收到」后台能查到该工牌已确认（ack_at 有值）
    3离线补拉某标签页先「断开」，发广播后再「连接」重连后能收到刚才错过的广播

    五、注意事项

  • 3 个标签页都要点「连接」，否则收不到广播。
  • 页面里「按住说话」「OK」「打断」等是翻译功能，测广播时不用管。
  • 某个标签页收不到广播时，先点「断开」再「连接」重试。
