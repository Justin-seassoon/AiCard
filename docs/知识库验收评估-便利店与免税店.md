# 知识库验收评估报告 · 便利店与免税店

> 评估对象：`docs/演示知识库-便利店与免税店.md`
> 评估身份：便利店 / 免税店业主方（区域运营总监 / 加盟店主 / 免税店经营者）
> 评估目的：判断该知识库能否用于销售演示与融资募资展示，是否会在内行客户 / 投资人面前翻车
> 评估日期：2026-09-06

---

## 一、验收结论

**有条件通过（列必改项）** —— 框架完整、多数硬数字准确，但存在 3 处「免税制度」相关的硬伤和「中文未日语化」的演示性硬伤，必须在演示前修正，否则在内行免税店业主或投资人面前会当场翻车。

---

## 二、总体评价

这份知识库作为「便利店 / 免税店通用底稿」是合格的：16 大主题覆盖了收银、年龄确认、税制、库存、食品期限、卫生、设备、便民、免税、客怨、防犯、深夜一人值班、加盟店角色边界、劳动管理，结构贴近真实店长手册，且多数易错数字（成年年龄与饮酒吸烟年龄的差异、消費期限 / 賞味期限区别、HACCP 温度、深夜加算、休息时间、留学生工时）都抓对了。

但它距离「拿去给内行免税店业主 / 投资人演示而不翻车」还差一次「时效性 + 免税细节」的硬校验：免税金额门槛的「合算」表述是错误、免税手续流程新旧制度前后矛盾、整体仍为中文未日语化——这三点是硬伤。更重要的是，知识库几乎没有覆盖「多语种接客 / 访日外国人服务」场景，而这恰恰是本产品「AI 语音翻译」的核心卖点，二者脱节会让演示显得「产品与知识库不是一回事」。

---

## 三、亮点

1. **易错硬数字基本全对**：成年 18 岁但饮酒吸烟仍禁 20 岁（§2）、消費期限 vs 賞味期限（§5）、HACCP 中心温度 75℃/1 分钟与保温 65℃/冷藏 ≤10℃/冷冻 ≤-18℃（§6）、深夜 22〜5 时加算 25% 与 18 岁未满禁止深夜劳动（§14）、休息 45/60 分（§16）、留学生每周 28 小时（§16）——这些是便利店培训里最容易错的地方，这份稿子没有写错，说明整理者对日本劳动与食品法规有基本掌握。

2. **免税制度改革方向抓到了**：§11 末尾（第 204 行）已主动标注「正由购买时免税向出境时退税（リファンド方式）过渡」，说明不是照抄旧教材，有在跟进 2026 年的税制改动。

3. **加盟店角色边界写得到位**：§15 明确「店员不越权承诺经营判断（开店时间、进货决策、投诉裁量属オーナー/店长权限）」，加上 §12 カスハラ应对、§13 万引き应对「不身体拘束、以人身安全为先」，体现了对日本服务业「现场作业员 vs 经营者」合规文化的理解，这是投资人会认可的专业度。

## 四、问题清单

### P0（错误 / 会翻车，必须改）

**P0-1 · 免税金额门槛「合算」表述错误**
- 位置：§11 免税商品与金额门槛，原文「一般品与消耗品分别计算（合算满足 5,000 日元也可免税，但消耗品需封装）」。
- 问题：日本免税规则是**一般品、消耗品各自**在同一店、同一日合计达到税抜 5,000 日元才可免税，**二者不可合算凑门槛**。例：一般品 3,000 円 + 消耗品 3,000 円，各自都未达 5,000 円，**不能**免税；原文「合算满足 5,000 日元也可免税」会直接误导店员，免税店业主一眼识破。
- 修改建议：改为「一般品、消耗品分别计算，各自须达到税抜 5,000 円门槛；一般品与消耗品**不可合算**凑门槛；消耗品另受 50 万日元上限约束并须封装」。

**P0-2 · 免税手续流程新旧制度前后矛盾、时效性未隔离**
- 位置：§11 免税手续流程（第 196–197 行）仍按旧「购买时免税」写完整流程（出示护照 → 免税店终端读取 → 按免税价结算 → 电子记录），而第 204 行又写「正逐步向出境时退税过渡」，两处直接冲突。
- 问题：免税制度正由「购买时免税」向「出国时退税（リファンド）」迁移（2026 年秋实施，具体日期演示前必须核对）。若演示发生在制度切换后，§11 前半套流程全部失效；即使演示时尚未切换，前后矛盾也会被内行投资人抓住。这是免税店业主最敏感的议题，属必改。
- 修改建议：把「旧流程」与「新流程」分节隔离，明确标注各自生效时点；补一段「新制度（リファンド）下的接待说明口径（全额收税 → 出境退税 → 引导到海关/专用终端）」，并在交付前由客户核对实施日期。

**P0-3 · 演示语言与产品卖点脱节：中文知识库无法支撑日语问答演示**
- 位置：全文头部「语言：中文梳理……正式录入前需日语化」。
- 问题：产品演示场景是「店员用日语提问 → 系统检索知识库 → 语音回答」，但知识库目前是中文，检索与 TTS 回答链路在日语提问下无法正常工作。若演示口径声称「支持日语问答」，这是演示级翻车。
- 修改建议：演示前至少把**演示会实际用到的 top 条目**日语化并录入向量库；若来不及全量日语化，明确降级口径（如「中文提问 → 中文回答」的内部演示，或预置日语问答对兜底）。

### P1（不准确 / 过时，应改）

**P1-1 · 購入記録票废止时间错误**
- 位置：§11 免税手续流程，原文「購入記録票制度已废止（2020 年起改为电子记录并传送海关）」。
- 问题：免税购入记录的电子化、废止护照贴附的纸质「購入記録票」是 **2021 年 10 月 1 日**起，不是 2020 年。
- 修改建议：改为「2021 年 10 月起，免税购入记录改为电子传送海关，纸质購入記録票废止」。

**P1-2 · 「外食」术语误用**
- 位置：§3 消费税与税率，原文「店内饮食（イートイン/外食）适用 10%」。
- 问题：「外食」是税法专有名词，指「餐饮服务的提供」，不是「店内饮食」的同义词。便利店语境正确表述是「店内有桌椅的イートイン＝视同外食 → 10%；持ち帰り → 8%」。现表述会把「外食」和「イートイン」并列成同义词，误导店员。
- 修改建议：改为「店内饮食（イートインスペースのある場合）＝外食扱い → 10%；持ち帰り → 8%」。

**P1-3 · 適格請求書表述过宽，易误导店员手开インボイス**
- 位置：§3 適格請求書制度，原文「企业客户索取发票时，按店铺规定开具適格請求書」。
- 问题：便利店面向不特定多数消费者，原则上只发行「適格簡易請求書」（即レシート），一般不开具标准「適格請求書（インボイス）」。现表述易让店员误以为要为企业客户额外手开インボイス。
- 修改建议：改为「原则上以レシート（適格簡易請求書）充当適格請求書；是否额外开具インボイス按本部规定执行」。

### P2（可优化）

**P2-1 · レジ袋有料化未提例外**
- 位置：§1 收银，原文「塑料袋自 2020 年 7 月起原则上收费」。
- 问题：未提「バイオプラスチック袋等属対象外（可免费）」的例外，顾客常问「这个袋子也收费吗」。
- 修改建议：补充「生物降解材质袋等属対象外」的口径，并按店铺实际价格口径填写。

**P2-2 · チルド与冷蔵温度带混同**
- 位置：§4 温度带管理（第 74 行），「チルド/冷蔵」统一归为 0〜10℃。
- 问题：チルド（chilled）通常比普通冷蔵更低温（0℃ 前後〜5℃，部分门店 -5〜5℃），混同会误导补货摆放。
- 修改建议：按本部温度带基准补充チルド单独区间。

**P2-3 · 賞味期限过期后的销售口径缺失**
- 位置：§5 食品ロス与期限管理。
- 问题：只写了「过期不等于立即变质」，未明确实操口径：消費期限切れ＝絶対販売停止/廃棄，賞味期限切れ＝可（在品质无虞前提下）打折销售或按本部指引处理。这是店员高频实操判断点。
- 修改建议：补充「消費期限切れ不可售、賞味期限切れ按本部指引打折/处理」的明确口径。

**P2-4 · 积分/ATM 品牌口径未按门店替换**
- 位置：§9 积分卡（dポイント/Ponta/楽天等）、§7 ATM（セブン銀行/イーネット/ローソン銀行）。
- 问题：积分体系与 ATM 网络是品牌强绑定（セブン→dポイント/セブン銀行、ファミマ→FamiPay/イーネット等），演示时用错自家品牌积分/ATM 会被识破。
- 修改建议：交付前按客户实际加盟品牌，把积分与 ATM 名称替换为单一品牌口径。

**P2-5 · 烟草自贩机 / taspo 缺失**
- 位置：§2 烟草销售。
- 问题：未提「たばこ自動販売機需 taspo 成人识别卡」及门店若配置自贩机的年龄确认方式。
- 修改建议：若门店含烟品自贩机，补充 taspo 口径。

**P2-6 · 万引き应对「不身体拘束」口径可更准确**
- 位置：§13 万引き発見時対応。
- 问题：原文「避免直接身体拘束」方向正确，但日本法律上「現行犯可私人逮捕」；更专业的口径是「原则上不身体拘束，以通報、映像保全、证人证言为主，私人逮捕仅限万不得已且按本部指引」。
- 修改建议：补充上述区分，避免店员因「完全不能动手」或「可以随便抓」两端误读。

## 五、关键遗漏

1. **多语种 / 访日外国人接客场景（P0 级遗漏，最致命）**
   产品卖点是「AI 语音翻译」，但知识库几乎零覆盖「用外语接待外国顾客」：免税手续的多语种说明、常见英语/中文/韩语问询（ATM 取现、退税、Wi-Fi、地图、交通、厕所）、以及应对语言不通时的基本话术。演示时投资人/客户第一个问的往往就是「你的知识库能不能帮店员用外语答疑」，现稿直接答不上。

2. **外貨両替（外币兑换）**
   观光区便利店与免税店的高频服务，部分门店设有人工兑换或外币取现 ATM，完全缺失。

3. **急救 / 突发疾病 / 灾害应对（AED、熱中症、誤嚥、食物过敏、地震、火灾、停电）**
   便利店在日本是「災害時拠点」，AED 使用、熱中症处置、异物呛住（誤嚥）、地震/火灾疏散引导、停电停水应对是员工培训核心。尤其「食物过敏原标识（特定原材料 8 品目）咨询」是外国游客高频问询，现稿只在 §6 提到「不同过敏原食品分开操作」，没有面向顾客的过敏原应答口径。

4. **FF 即食食品（炸鸡 / 关东煮 / 肉まん / おでん）制作、温度与废弃**
   这是便利店日配的核心商品与损耗大头，现稿只写了「现磨咖啡机」和一笔带过的「加热食品」，缺 FF 的制作、保温时限、见切与废弃标准。

5. **接客基本用语（接客 8 大用語）与开闭店作业**
   缺系统化的接客用语/礼仪（いらっしゃいませ、ありがとうございました等）与開店準備/閉店作業（开门前防犯确认、闭店清场、保险柜、通報装置确认）流程。

---

## 六、给决策者的一句话建议

改完 3 个 P0（免税门槛「合算」表述、免税新旧制度流程统一、演示条目日语化）再上演示，否则免税店业主和投资人会当场识破；同时补齐「多语种接客 / 外貨両替 / 急救·灾害」三条，才能让知识库与「AI 翻译」卖点真正咬合，而不是两张皮。
