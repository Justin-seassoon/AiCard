## 経費精算

**Q：経費精算の締め日はいつですか？**
A：毎月末日締めです。当月分は翌月10日までに総務部へ提出してください。

**Q：経費精算の提出期限は？**
A：当月分は翌月10日までに提出してください。10日を過ぎた分は翌々月の精算になります。

**Q：交通費はどうやって精算しますか？**
A：交通費精算書に領収書を添付し、所属長の承認を得たうえで総務部へ提出してください。

**Q：領収書をなくしてしまいました。再発行できますか？**
A：はい。総務部に申請すれば再発行できます。手数料はかかりません。

## 備品購入

**Q：備品購入の申請フローを教えてください。**
A：①備品購入申請書を作成 → ②所属長の承認 → ③総務部へ提出 → ④総務部が発注、の順です。5万円以上の場合は部長の承認も必要です。

**Q：備品購入の申請には何が必要ですか？**
A：備品購入申請書、見積書、購入理由書の3点が必要です。

## 社内手続き

**Q：回覧文の出し方は？**
A：回覧文を作成し、総務部の確認後に各部へ回覧してください。回覧後は署名欄を確認して総務部へ返却します。

**Q：有給休暇の申請方法を教えてください。**
A：勤怠システムから申請し、所属長の承認を得てください。急な場合は総務部へ電話で連絡してください。

**Q：会議室の予約方法は？**
A：社内ポータルの会議室予約から予約してください。1時間単位で予約できます。

## 施設・設備

**Q：駐車場はありますか？**
A：来客用駐車場が5台分あります。ご利用の際は事前に総務部へご連絡ください。

**Q：Wi-Fi のパスワードは何ですか？**
A：社内 Wi-Fi の SSID とパスワードは、入社時に配布される案内をご確認ください。

**Q：備品が故障した場合はどうすればいいですか？**
A：総務部へ連絡し、修繕オーダーを起票してください。緊急の場合は電話で連絡してください。
