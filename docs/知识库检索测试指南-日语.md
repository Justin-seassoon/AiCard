# 知識ベース検索テストガイド（知识库检索测试指南）

> 用途：给懂日语的测试人员，用于在测试页（`http://<服务器>:8080/`）逐条输入问题，验证知识库检索命中率与答案准确性。
> 用法：按下面问题逐条输入测试页 → 记录「命中/未命中」及答案是否正确。
> 覆盖：便利店（含免税店）＋ 连锁酒店，共两个行业。
