# AI 工牌 · 客户推介手册（分行业）

> 一句话：AI 工牌是一线员工佩戴的 AI 助手——说母语就能和游客/劳工对话，总部知识随时在耳边，还能帮你卖货、帮你调度。**它帮你把事做成，不是监控你。**

---

## 一、这是什么

一个工牌大小的可穿戴终端，一线员工（店员 / 柜员 / 地勤 / 劳工 / 班组长）戴在胸前。短按一下开始，之后不用再碰它：

- 你说中文 / 越南语 / 印尼语…，对方听到的是日语；对方说日语，你听到的是你的母语
- 遇到不会答的问题，工牌从总部知识库直接给出标准答案
- 店长发一条通知，一句话同时变成中日越多国语言，送到每个员工耳边

关键指标：端到端响应 **不到 1.5 秒**，佩戴待机 **7–10 天**，收音距离 **0.5–1.5 米**，连续对话中途**无需每句按键**。

---

## 二、它能帮你做的五件事

1. **翻译（入口）**：多语种实时双向语音翻译，连续对话不断句按键
2. **知识（总部替你记住）**：SOP、规则、安全须知，问就答，答案带来源
3. **推荐（帮你卖货）**：识别品牌词，游客问「护肤品推荐」直接给专业答案
4. **调度广播（帮你协调）**：多语种一键通知 / 派工 / 停工，谁收到谁确认
5. **数据（越用越聪明）**：高频问题回流 → 补知识 → 下次答得更好

## 三、分行业价值

### A 面 · 面向游客的服务业

#### 🏨 连锁酒店

- **痛点**：多语种游客问路 / 入住 / 投诉，前台靠手势和翻译 App，标准 SOP 记不住
- **工牌帮什么**：前台和游客直接对话；「台风退房怎么处理」这类 SOP 即时答；游客问「有什么好吃的」顺手推荐晚餐 / 增值服务
- **量化收益**：客单价 ↑（推荐）、投诉 ↓（答得对）、培训成本 ↓（新人不用背 SOP）

#### 🛍 免税店

- **痛点**：游客咨询密集、品牌词易误翻、退税规则复杂
- **工牌帮什么**：品牌词不误翻（龙角散 / 资生堂 / SK-II）；给游客专业推荐；退税规则即时答
- **量化收益**：客单价 ↑、爆款备货精准、退税差错 ↓

#### ✈️ 机场

- **痛点**：多语种旅客、安检 / 转机规则随时变、登机口变更通知难触达
- **工牌帮什么**：安检规则即时答、登机口变更多语种广播到旅客耳边
- **量化收益**：服务效率 ↑、投诉 ↓，机场服务标杆

### B 面 · 面向外国劳工的行业

#### 👥 劳务派遣（制造 / 餐饮 / 农业 / 介护 / 清扫）

- **痛点**：外国劳工日语参差，岗前 / 安全培训重，派工 / 合规管理难
- **工牌帮什么**：劳工 ↔ 管理者实时翻译；培训下沉（安全 / 操作 / 接客）；派工 / 停工母语广播；在留到期提醒
- **量化收益**：到岗率 ↑、培训成本 ↓、合规风险 ↓、事故 ↓

#### 🏗 工地

- **痛点**：多国劳工、安全指令易失真、台风停工通知难触达
- **工牌帮什么**：安全翻译不失真；安全知识即时答；台风停工母语广播
- **量化收益**：事故 ↓（人命关天，最硬 ROI）、培训成本 ↓

---

## 四、为什么不是「又一台翻译机」

- 翻译机是**硬件一次性买卖**，工牌是「越用越懂你门店」的 **agent**
- 答案**带来源**（证据链），判断留给你的一线员工，不替代人
- 采集数据是为了「**下次答得更好**」，不是为了「抓谁偷懒」

---

## 五、怎么落地

- **硬件**：ODM 成熟联网音频方案，快速量产（样机已交付）
- **云端**：多供应商（科大讯飞 / 火山 / 谷歌 / 腾讯），不锁死、成本可控
- **试点**：选一家门店，两周跑通，用「客单价 / 投诉 / 事故 / 培训成本」算一笔账

---

## 六、下一步

约一次现场演示：带真机到你的门店，走一遍「翻译 → 知识 → 推荐 → 调度」全流程。你看到的是**一线员工多卖了多少、少出多少错**，而不是一台会说话的机器。
