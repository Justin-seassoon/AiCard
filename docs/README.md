## 维护约定

- **新增或更新基线** → 更新本页「★ 唯一基线」与相应文档的状态。
- **新增文档** → 归入上表相应分区；历史类按日期追加。
- **非 md 生成物**（docx / html / pdf）→ 放 `exports/`（基线 HTML 除外，与源文件同放 `baseline/`）。
- **代码/迁移变动后** → 跑 `bash scripts/status-audit.sh`；报 ⚠️ 说明有漂移，须回写基线（并更新技术基线 §7「代码锚点」表）。
- 加迁移 → 更新 `baseline/数据库说明.md`；改租户/异步等约定 → 更新 `baseline/开发指南.md`。
- 发现文档与实现不符 → 提醒更新（双方约定）。
